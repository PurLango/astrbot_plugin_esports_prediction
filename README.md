# 赛事积分竞猜

面向 AstrBot 群聊的电竞赛事胜者竞猜插件。机器人自动收集赛程与赛果，群成员使用 Bot 内的虚拟积分竞猜，比赛结束后自动结算。

> 本插件只使用没有现实价值、不可提现或兑换现金的虚拟积分。

- 当前版本：`2.4.4`
- 最低 AstrBot 版本：`4.22.0`
- 数据来源：[PandaScore](https://pandascore.co/)

## 支持赛事

- 英雄联盟：LPL、LCK、先锋赛（First Stand）、MSI、全球总决赛（Worlds）
- 无畏契约：VCT Americas、EMEA、Pacific、China 四大赛区正赛，以及 Masters、Champions

其他赛事会在同步时直接忽略。

## 主要功能

- 自动同步指定一线赛事的赛程、比赛状态与最终结果
- 同步结果只保留筛选后的比赛；首次发现时已经取消的比赛不收录
- 已收录后取消的比赛保留记录并退款；完赛结果在运营台展示 24 小时
- 群聊赛事列表、详情和竞猜结果优先显示 PandaScore 提供的官方战队缩写
- 第一版仅竞猜比赛胜者
- 根据历史赛果运行 Elo 模型，生成双方胜率与竞猜倍率
- 第一笔下注后锁定该场倍率，避免比赛过程中发生变化
- 同一用户在不同群对同一比赛的下注会合并为一笔全局记录
- 支持同队追加、改选和撤单
- 比赛结束后自动结算；取消、延期等异常比赛统一全额退款
- 展示盈利榜、命中率榜和总返还榜
- 在原积分运营台内提供赛事竞猜管理页签
- 首版不主动播报，用户通过指令查询赛事和结果

## 竞猜规则

- 每次下注最低 `10` 积分，每人每场累计最高 `10,000` 积分
- 开赛前 `30` 分钟封盘，封盘后不能新下注或继续追加
- 开赛前 `60` 分钟截止改选与撤单
- 同一队伍可以多次追加，累计金额不得超过单场上限
- 猜中返还：`下注积分 × 锁定倍率`，结果向下取整
- 未猜中不返还本金；异常比赛原额退款
- 比赛、下注和排行榜均为 Bot 全局数据，不按群重复建立

倍率由插件根据已同步历史赛果的 Elo 实力评分计算，不读取博彩盘口。PandaScore 负责提供赛程、状态和赛果。

## 安装

1. 下载或克隆本仓库。
2. 将插件放入 AstrBot 的 `plugins` 目录。
3. 为兼容原积分数据，建议插件目录保持为 `astrbot_plugin_point_system`。
4. 重启 AstrBot 或在插件管理中重新加载。
5. 在插件配置中填写 PandaScore Token，并配置积分管理员账号。

插件本身没有额外的第三方 Python 依赖，运行环境由 AstrBot 提供。

## 首次配置

在 AstrBot 插件配置中找到 `esports_prediction_settings`：

- `enabled`：启用赛事竞猜
- `pandascore_token`：PandaScore API Token
- `games`：同步 `lol`、`valorant` 中的哪些项目
- `sync_enabled`：启用定时自动同步
- `sync_interval_minutes`：同步间隔，默认 `10` 分钟
- `min_bet` / `max_bet`：单次最低与每场累计最高下注
- `switch_deadline_minutes`：改选和撤单截止时间
- `close_before_minutes`：封盘时间
- `elo_k_factor`：Elo 评分更新速度
- `odds_margin`：模型倍率边际
- `timezone_offset_hours`：显示和手动录入赛事所用时区，默认 `UTC+8`

PandaScore Token 只应保存在 AstrBot 本地配置中，不要发送到群聊或提交到仓库。未配置 Token 时，管理员仍可手动添加、结算和退款。

积分管理员由 `admin_settings.points_admin_ids` 配置。测试时可先使用 `/给积分 @用户 1000` 发放虚拟积分。

## 用户指令

| 指令 | 作用 |
| --- | --- |
| `/今日赛事` | 按开赛时间查看最多 10 场仍可参与的今日及近期赛事 |
| `/赛事详情 编号` | 查看比赛时间、胜率、倍率、奖池和截止时间 |
| `/竞猜 编号 战队缩写 积分` | 使用列表中的官方缩写竞猜胜者；也兼容 `1`、`2` 或全名 |
| `/改选 编号 战队缩写` | 在截止时间前更换所选队伍；也兼容 `1`、`2` 或全名 |
| `/撤销竞猜 编号` | 在截止时间前撤单并退回本金 |
| `/我的竞猜` | 查看最近的个人竞猜记录 |
| `/竞猜排行` | 同时展示盈利、命中率和总返还榜 |
| `/竞猜规则` | 查看当前 Bot 实际采用的规则 |
| `/我的积分` | 查询可用于竞猜的积分余额 |
| `/群聊签到` | 获取基础虚拟积分 |

示例：

```text
/今日赛事
/赛事详情 L1234567
/竞猜 L1234567 TES 100
/改选 L1234567 BLG
/撤销竞猜 L1234567
```

## 管理员指令

| 指令 | 作用 |
| --- | --- |
| `/竞猜管理 同步` | 立即同步赛程、赛果并执行自动结算 |
| `/竞猜管理 添加 游戏\|赛事\|队伍A\|队伍B\|时间` | 手动添加比赛 |
| `/竞猜管理 结算 编号 队伍` | 手动指定获胜队伍并结算 |
| `/竞猜管理 退款 编号` | 全额退回该场所有待结算下注 |
| `/竞猜管理 封盘 编号` | 立即停止下注 |
| `/竞猜管理 隐藏 编号` | 从用户赛事列表隐藏比赛 |
| `/竞猜管理 显示 编号` | 重新显示比赛 |

手动添加示例：

```text
/竞猜管理 添加 lol|LPL|BLG|TES|2026-09-01 19:00
```

## 积分运营台

入口：`AstrBot 管理面板 → 插件 → 赛事积分竞猜 → 积分运营台`，然后打开“赛事竞猜”页签。

管理页面可以：

- 配置 PandaScore Token、同步开关和游戏范围
- 查看比赛状态与竞猜开放状态，并按游戏筛选
- 手动同步或添加比赛
- 封盘、隐藏、显示、退款和结算

## 数据与兼容

- 插件标识继续使用 `astrbot_plugin_point_system`，用于兼容原积分账户和已有数据
- 主数据文件：`<AstrBot数据目录>\plugin_data\astrbot_plugin_point_system\points_data.json`
- 竞猜数据与积分数据一起原子保存，并沿用原插件的自动备份能力
- 旧数据加载后会自动迁移到当前数据版本

本项目基于 [menglimi/astrbot_plugin_point_system](https://github.com/menglimi/astrbot_plugin_point_system) 扩展开发，原插件提供了积分账户和持久化基础。
